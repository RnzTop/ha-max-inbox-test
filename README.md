# MAX — стенд уведомлений для Home Assistant

Отдельное тестовое дополнение для Raspberry Pi arm64 (aarch64). Панель показывает только искусственные карточки. Она не подключается к MAX и не требует токена.

Добавьте адрес этого репозитория в **Магазин приложений → ⋮ → Репозитории**. Установите **MAX — стенд уведомлений**, запустите и откройте веб-интерфейс. Нажмите «Загрузить три тестовых сообщения», назначьте сотрудника и перезапустите стенд. Карточки и назначение сохранятся.
